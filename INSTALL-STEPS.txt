AutoBlog Pro v13 Fresh Client Instances

1. Deploy code to /opt/autoblog.
2. Reinstall server and client dependencies.
3. Build client.
4. Restart main backend.
5. Open https://domaincontroller.in/?v=13
6. Login: admin / admin@2020
7. Clients -> add page name global1 -> Create Client App.
8. Open https://domaincontroller.in/global1/?v=13
9. Login to client: admin / admin@2020
10. Security -> change that client's password.

v13 difference:
- main site and client site no longer share the same backend process.
- each client gets its own Node process, port, Mongo DB, auth file, and logs.
