AUTOBLOG PRO V18.3 DEEP STABILITY FIX — INSTALL

A. BACKUP FIRST
1. Back up the WordPress files and database.
2. Back up /opt/autoblog, /opt/autoblog/server/.env, and /opt/autoblog/server/data.
3. Do not delete the existing .env or data directories during the code update.

B. WORDPRESS PLUGINS
1. WordPress Admin -> Plugins -> Add New -> Upload Plugin.
2. Upload sem-seo-bloger-v5.6.0-deep-stability-fix.zip.
3. Choose Replace current with uploaded, then Activate.
4. Upload wp-gamini-remote-bridge-v2.8.0-deep-stability-fix.zip.
5. Choose Replace current with uploaded, then Activate.
6. Confirm WordPress shows only one active SEM SEO BLOGER and one active Remote Bridge.
7. Open AutoBlog Bridge. Confirm SEM SEO BLOGER is Ready and copy the Bridge key.

C. DASHBOARD APPLICATION
1. Extract autobllog-main-v18.3-deep-stability-fix.zip to a temporary directory.
2. Copy its application files into /opt/autoblog, but preserve:
   - /opt/autoblog/server/.env
   - /opt/autoblog/server/data
3. Compare your .env with server/.env.example. Recommended additions/updates:
   BRIDGE_TIMEOUT_MS=30000
   BRIDGE_RUN_TIMEOUT_MS=240000
   BRIDGE_AI_TIMEOUT_MS=90000
   BRIDGE_UPLOAD_TIMEOUT_MS=180000
   JSON_LIMIT=16mb
   PLUGIN_UPLOAD_JSON_LIMIT=96mb
   CLIENT_PROXY_TIMEOUT_MS=300000
4. Install/build:
   cd /opt/autoblog/server && npm ci --omit=dev --no-audit --no-fund
   cd /opt/autoblog/client && npm ci --no-audit --no-fund && npm run build
5. Restart only the process manager already used on your server: PM2, systemd, or nohup. Do not run two copies on port 4000.
6. Test locally:
   curl -fsS http://127.0.0.1:4000/api/healthz
   Confirm appVersion is v18.3-deep-stability-fix.
7. Check Nginx has client_max_body_size 100m and proxy_read_timeout/proxy_send_timeout 300s.
8. Run nginx -t, reload Nginx, and hard refresh the browser with Ctrl+Shift+R.
