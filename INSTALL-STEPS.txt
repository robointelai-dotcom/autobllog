AutoBlog Pro v18 Random Hourly Scheduler install steps

1. Push the dashboard code to GitHub using GITHUB-SERVER-UPDATE-COMMANDS.txt.
2. Pull the latest code on VPS /opt/autoblog.
3. Reinstall server and client dependencies.
4. Run client build.
5. Restart main backend and client instance backends.
6. Open https://domaincontroller.in/?v=18 and hard refresh.
7. Go to Sites and choose Random hourly schedule mode.

For 1 post per hour with random timing:
- Mode: Random hourly
- Random hrs: 1
- Random minute min: 0
- Random minute max: 59
