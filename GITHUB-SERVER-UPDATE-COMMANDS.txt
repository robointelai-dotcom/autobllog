Nginx white-screen fix
----------------------
If /global1/ or /tes/ opens blank white, your Nginx is serving static files directly and not passing /clientSlug/ to Node.
Change Nginx so location / proxies all traffic to 127.0.0.1:4000.
A sample file is included: NGINX-PROXY-ALL-FIX.conf
